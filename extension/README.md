# 图文教程采集器 · 安装与使用

## 安装（一次性，约 1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点左上角 **加载已解压的扩展程序**，选择本目录（`...\skills\tutorial-maker\extension`）
4. 工具栏出现蓝色「教程」图标即安装成功（可点拼图图标把它固定到工具栏）

Edge 同样可用：`edge://extensions` → 开发人员模式 → 加载解压缩的扩展。

## 使用

1. 打开要演示的网页（**开始采集时所在的站点，就是本次要录的站点**）
2. 点扩展图标 → **开始采集**（图标上出现蓝色数字角标，弹窗会显示"只录：xxx.com"）
3. 正常操作：点击、填写、提交，跟平时一样
4. 中途要看别的网站，先点 **暂停采集**（角标变成 ⏸），回来说 **继续采集**
5. 操作完点 **结束采集**
6. 点 **导出素材（JSON）**，文件落到浏览器下载目录

### 只录目标站点

开始采集时会记住当前域名，之后：

- 切到别的网站（小红书、搜索引擎、邮箱）→ **自动忽略**，不占配额、不进文件
- 在目标站点的不同页面/路径间跳转 → 正常记录
- 切回来继续操作 → 自动恢复记录

弹窗会显示「已忽略 N 条站外动作」。这样就不会再出现文件里混进几十条无关浏览的情况。
6. 把 JSON 发给我，或自己执行：
   ```bash
   python scripts/import_capture.py tutorial-capture-xxxx.json capture
   python scripts/render.py capture/steps.json 成品目录
   ```

## 它会记什么

| 记录项 | 说明 |
|---|---|
| 每一步的截图 | 原生 PNG，无视频压缩，文字锐利 |
| 被点元素的精确边界 | 用于自动画高亮框，误差 ≤1px |
| 元素文字 / placeholder | 作为文案素材，省去人工描述 |
| 敏感输入框位置 | 手机号、密码、邮箱、身份证、银行卡、验证码格 |
| 每帧的滚动位置 | `scrollY` / `docH`，用于把同页多帧拼成整页长图 |

### 截图取的是"点击前"的画面

鼠标在可点击元素上停留 320ms，扩展会先悄悄拍一张。点击发生时优先用这张预截图。
这样拿到的选项是**未被置灰的原貌**，而不是点完变灰的样子。预截图不额外占用截图配额。

### 滚动也会补拍（1.1.0 起）

点击只发生在有交互的地方。长页面里纯阅读的段落（表单中段、条款正文、结果页下半）如果没有滚动补采，导出后就是整段缺图。

滚动停止 420ms 后，若本次滚动幅度超过半屏，扩展补拍一帧，标记为滚动帧。弹窗会显示「含滚动补采 N 张」。

滚动帧同样带 `scrollY`，所以事后可以按页面坐标把多张拼成完整长图，重叠区精确到 1 像素。这个数没法用图像匹配替代——表单插入报错提示会改变布局，图像对齐会错。

## 隐私边界（重要）

- 数据**只存在本机** Chrome 的扩展存储里，不上传任何服务器
- 密码与验证码的明文**从不写入存储**，文本一律记为 `••••`
- 截图本身是原图，打码在导出后由本地脚本完成
- 扩展不读取页面正文内容，只读被操作元素的位置与文字

## 已知限制

1. **截图频率硬上限**：Chrome 限制每秒最多 2 次。操作过快时，该步会**保留记录但没有图**（导出时提示「丢弃 N 步」）。建议每次操作间隔 0.5 秒以上。
2. **只采集主文档**，iframe 内的操作不记录。
2b. **域名限定有副作用**：跨域跳转的流程（例如跳到第三方支付页、跳去邮箱拿验证码）不会记录。这类流程请用「暂停/继续」手动控制，或临时关闭限定。
3. **浏览器内部页面不采集**（`chrome://`、扩展商店等）。
4. **页面跳转的瞬间**可能截到过渡态或新页面，需要时重新操作一次。
5. **纯文本的手机号**（如页面上显示"已发送至 138\*\*\*\*8000"）不会被自动打码，需人工补标注。
6. **滚动补采不是自动长截图**：它只在停留处补一帧，不会把整页一次性拍全。滚动中途页面若发生布局变化（报错插入、下拉展开），拼接会出现错位，此时以原始帧为准。

## 卸载

`chrome://extensions` → 找到本扩展 → 移除。已采集的数据随扩展一起清除。
